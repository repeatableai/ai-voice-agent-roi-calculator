## 🚀 Deployment Options

### Option 1: Render (Recommended - One Service)
**Configuration:** `render.yaml` is already set up

1. Go to https://render.com
2. New → Blueprint
3. Select repo: `repeatableai/ai-voice-agent-roi-calculator`
4. Render detects `render.yaml` and creates service `aiva`
5. Add environment variables:
   - `ANTHROPIC_API_KEY`
   - `OPENAI_API_KEY`
6. Deploy

**Result:** One URL serves both frontend and backend
- Frontend: `https://aiva-xxxx.onrender.com/`
- API: `https://aiva-xxxx.onrender.com/api/aiva/...`

### Option 2: Separate Frontend/Backend
**Frontend (Vercel/Render Static Site):**
- Root Directory: `AIVA`
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`
- Environment Variable: `VITE_API_URL=https://your-backend-url`

**Backend (Render/Railway):**
- Root Directory: `backend`
- Start Command: `npm start`
- Port: 10000 (Render) or auto (Railway)
- Environment Variables: API keys + CORS_ORIGIN

## 🐛 Troubleshooting

### "Network Error: Failed to execute 'json' on 'Response'"
**Fixed!** The app now handles:
- Non-JSON responses gracefully
- Empty responses
- Network errors with helpful messages

### Backend Not Connecting
1. Check backend is running: `curl http://localhost:8080/health`
2. Check `VITE_API_URL` is set correctly (or use relative URLs)
3. Check CORS configuration on backend
4. Check browser console for detailed errors

### Frontend Not Loading
1. Ensure frontend is built: `cd AIVA && npm run build`
2. Check backend serves `AIVA/dist` correctly
3. Verify path resolution in backend logs
