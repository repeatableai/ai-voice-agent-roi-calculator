# 🚀 Render Deployment - Super Simple

**Just follow these 3 steps. Everything else is automated.**

## Quick Deploy

1. **Backend**: Use Blueprint (automatic) → Add API keys
2. **Frontend**: Create Static Site → Root Directory = `AIVA`
3. **Connect**: Set CORS_ORIGIN = frontend URL

**Full instructions:** See `RENDER_SIMPLE_SETUP.md`

---

## Why This Setup?

- **Backend**: Uses `render.yaml` Blueprint (automatic)
- **Frontend**: Must be Static Site (Blueprint doesn't support it)
- **API Keys**: Already in your `.env` file, just copy-paste into Render

---

## Your API Keys

They're in `backend/.env`. Copy them into Render's Environment Variables.

See `RENDER_SIMPLE_SETUP.md` for exact copy-paste values.
