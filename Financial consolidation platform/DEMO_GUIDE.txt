UNDERSTANDING THE APP FEATURES
================================================================================

AI-Powered Mapping:
  • Analyzes account names intelligently
  • Provides confidence scores (75-99%)
  • Explains reasoning for each suggestion
  • Learns from industry context
  • Requires OpenAI API key (configured in .env)

Consolidation Engine:
  • Aggregates transactions across companies
  • Applies account mappings
  • Detects intercompany transactions
  • Performs eliminations automatically
  • Generates consolidated financials

Financial Reports:
  • Complete Balance Sheet (Assets = Liabilities + Equity)
  • Income Statement (Revenue - Expenses = Net Income)
  • Consolidation metadata (companies, eliminations, timing)
  • Multiple period selection
  • Professional formatting

Master Chart of Accounts:
  • Standardized account structure
  • 5 main categories (Assets, Liabilities, Equity, Revenue, Expenses)
  • Subcategories for organization
  • Consistent numbering scheme (1000s, 2000s, etc.)
