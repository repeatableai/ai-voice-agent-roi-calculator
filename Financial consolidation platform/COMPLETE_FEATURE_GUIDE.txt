NEW FEATURE #1: TRANSACTION IMPORT
================================================================================

Location: Transactions page (in navigation)

WHAT YOU CAN DO:
✅ Import transactions from Excel or CSV files
✅ Download CSV template with example data
✅ Drag & drop file upload
✅ See validation errors with row numbers
✅ View import results (success/error counts)
✅ View list of imported transactions

HOW TO USE:
───────────
1. Click "Transactions" in left navigation
2. Select a company from dropdown (e.g., "TechCorp USA")
3. Click "📥 Download Template" to get example CSV
4. Fill in your transaction data:
   - date: YYYY-MM-DD format
   - account_number: Must match company's account numbers
   - description: Transaction description
   - debit: Debit amount (or 0)
   - credit: Credit amount (or 0)
   - reference: Optional reference number
5. Drag & drop file to upload area (or click to browse)
6. Click "📤 Import Transactions"
7. See results: Success count and any errors

VALIDATION RULES:
- Date is required and must be valid
- Account number must exist in selected company
- Either debit OR credit must be > 0 (not both)
- Amounts cannot be negative
- Errors show row number and specific issue

TEMPLATE PROVIDED AT:
/Users/steen/ai-voice-agent/Financial consolidation platform/test_transactions.csv

EXAMPLE DATA:
date,account_number,description,debit,credit,reference
2025-01-15,1010,Cash receipts,75000,0,JAN-001
2025-01-20,4010,Software sales,0,50000,INV-1001
