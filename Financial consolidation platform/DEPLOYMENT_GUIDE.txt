QUICK DEPLOYMENT (3 COMMANDS)
================================================================================

1. Extract the archive:
   $ tar -xzf constellation-consolidator.tar.gz
   $ cd constellation-consolidator

2. (Optional) Add your OpenAI API key:
   $ nano .env
   # Add: OPENAI_API_KEY=sk-your-api-key-here

3. Start the application:
   $ ./start.sh

That's it! The application will be available at:
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000/docs


PREREQUISITES
================================================================================

✓ Docker Desktop
  - Download: https://www.docker.com/products/docker-desktop
  - Required for running the application
  - Must be running before executing ./start.sh

✓ OpenAI API Key (Optional, for AI features)
  - Get key: https://platform.openai.com/api-keys
  - Required only for AI-powered account mapping

COMMON COMMANDS
================================================================================

Start services:
$ ./start.sh

Stop services:
$ docker-compose down

View logs:
$ docker-compose logs -f

Check status:
$ docker-compose ps

Restart a service:
$ docker-compose restart backend

TROUBLESHOOTING
================================================================================

Problem: "Docker is not running"
Solution: Start Docker Desktop and wait for it to fully initialize

Problem: "Port already in use"
Solution: Stop conflicting service or edit docker-compose.yml to change ports

Problem: Frontend not loading
Solution: docker-compose logs frontend
         docker-compose restart frontend

Problem: Backend errors
Solution: docker-compose logs backend
         Check .env file is configured correctly
